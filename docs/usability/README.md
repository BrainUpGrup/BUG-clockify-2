# 📁 Documentación de Usabilidad y Propuestas de Diseño

Este directorio reúne los estudios de experiencia de usuario, auditorías de usabilidad y propuestas de rediseño visual elaboradas para la suite **Brain Up Hub (Clockify, TaskFlow y Coordinación)**.

---

### 📄 Documentos PDF Oficiales
1. **[Estudio_Usabilidad_Brain_Up_Grup.pdf](./Estudio_Usabilidad_Brain_Up_Grup.pdf)** (1.7 MB): Estudio completo de arquitectura de información, flujos de imputación y puntos de fricción.
2. **[Estudio_Usabilidad_Mejoras_Brain_Up.pdf](./Estudio_Usabilidad_Mejoras_Brain_Up.pdf)** (1.4 MB): Informe ejecutivo con las propuestas de mejora ergonómica y accesibilidad.
3. **[Propuesta_Diseno_Horas_Por_Cliente.pdf](./Propuesta_Diseno_Horas_Por_Cliente.pdf)** (1.6 MB): Propuesta gráfica de alta fidelidad para el desglose de horas por cliente y cuotas.
